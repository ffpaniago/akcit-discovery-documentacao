<Intro>

The `react-dom/client` APIs let you render React components on the client (in the browser). These APIs are typically used at the top level of your app to initialize your React tree. A [framework](learn/creating-a-react-app.md) may call them for you. Most of your components don't need to import or use them.

</Intro>

---

## Client APIs {/*client-apis*/}

* [`createRoot`](reference/react-dom/client/createroot.md) lets you create a root to display React components inside a browser DOM node.
* [`hydrateRoot`](reference/react-dom/client/hydrateroot.md) lets you display React components inside a browser DOM node whose HTML content was previously generated by [`react-dom/server`.](reference/react-dom/server.md)

---

## Browser support {/*browser-support*/}

React supports all popular browsers, including Internet Explorer 9 and above. Some polyfills are required for older browsers such as IE 9 and IE 10.
