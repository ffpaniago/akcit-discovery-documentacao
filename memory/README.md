# memory/

Histórico do trabalho executado neste repositório. **Append-only**: não se reescreve,
não se apaga.

O objetivo não é log de auditoria. É permitir que a próxima sessão — sua, de um colega
ou de um agente — retome o trabalho sem reabrir discussão já encerrada e sem repetir
uma investigação que já foi feita.

Formato: `AAAA-MM-DD-slug-da-tarefa.md`, seguindo o modelo descrito em `AGENTS.md`.
